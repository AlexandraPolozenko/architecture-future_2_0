## Домены

#### Клиента
Берет на себя всю работу с клиентами - записи на прием, отображение списка записей, результатов осмотра и пр. Доступен из внешнего интернета, хранит персональные данные, разделенные по клиентам

#### Сотрудника
Информация о записях, мед карты пациентов, часы работы, анализы. Доступен только сотрдуникам компании (врачам, сотрудникам ресепшена). 

#### Финансы
Информация о финансовых операциях. Оплаты записей на прием, отчеты и пр. Содержит в себе только финансовую информацию, никак не оперирует мед данными, недоступен для врачей и пр.

#### Аналитика
Данные для построения отчетов, обучения мл-моделей и пр. Используются только аналитиками, менеджментом и мл-специалистами.


## Преимущества
- Ускорение разработки. Каждый домен может развиваться независимо, отдельными командами. Параллельно могут разрабатываться разные модули.
- Безопаность. Можно разделить доступы для каждого из доменов.
- Повышение производительности и масштабируемости. Можно оптимизировать, ускорять, доливать ресурсами и пр каждый модуль независимо.
- Гибкость интеграции. Обособленные домены позволяют быстро подключать новые системы.
