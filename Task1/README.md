## Проблемные места

| Проблема                              | Описание                                                                                                                                                               |
|---------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Устаревший ДВХ                        | Поддержка текущих технологий закончилась в 2019 году, данные обрабатываются медленно, проблемы с масштабированием, угрозы безопасности                                 | 
| Данные и логика в ДВХ без разделения  | Добавление новой бизнес логики требует доработок и в общем ДВХ, все данные в одном месте (финансы, личные данные), что вызывает риск утечек, сложности масштабирования |
| Устаревший PowerBuilder               | Неудобный устаревший интерфейс, требуется большое количество ручных действий для построения отчета, для создания нового отчета нужно участие разработки                |
| Отсутствует система управления ролями | Риски утечки данных, несанкционированных изменений и пр                                                                                                                |


## Приоритезация проблем

#### Must
- Устаревший Microsoft SQL: При проблемах с работой/производительностью потенциальная остановка работы компании, блокирует масштабирование.
- Система управления ролями и разделение данных: Потенциально большие штрафы при утечке, репутационные риски

#### Should
- Деление на домены: Тормозит реализацию новой функциональности, потенциальный блокер при разделении данных
- Устаревшая интеграционная шина на Apache Camel: На данный момент долгая и ненадежная интеграция, что понижает производительность сотрудников и влечет риски некорректности данных.

#### Could
- Power Builder: Долгое построение отчетов и неудобный интерфейс, на данный момент не несет рисков, только усложняет работу
