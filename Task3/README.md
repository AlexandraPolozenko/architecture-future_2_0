## Обоснование этапов
Проектирование Data LakeHouse:
- Позволяет продумать изменения, запланировать работы
- Составить план безопасной миграции

Развертывание Data LakeHouse:
- Уменьшение ТТМ составления отчетов
- Уменьшение ТТМ подготовки данных для обучения моделей
- Масштабируемость (адаптируемся под возрастающие нагрузки)
- Производительность (ускорение построения отчета)

Миграция данных:
- Постепенный отказ от легаси хранилища
- Уменьшение затрат на поддержку
- Освобождение железа

Созадние новых витрин:
- Актуальные дашборды
- Повышение скорости загрузки дашбордов
- Отказ от легаси дашбордов

Ролевая модель:
- Повышение безопасности
- Репутационные риски
